# Ai-Inventory-management-system
AI-powered inventory dashboard for medical distributors. Upload a CSV or Excel file and Google Gemini classifies every product as Sell Off, Watch, or Keep &amp; Reorder based on stock movement and days-on-hand. No login — single-session upload-to-dashboard flow. Built with Next.js, Tailwind, Supabase, and Gemini; deploys to Vercel.
